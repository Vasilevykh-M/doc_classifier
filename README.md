# doc_classifier

Репозиторий содержит два решения для классификации документов, каждое с использованием разных подходов. Оба решения требуют GPU NVIDIA для работы и предоставляются в виде готовых Docker-образов.

### Особенности решений
* Contrastive-решение (ветка contrastive)
  * Подход: Использование контрастивного обучения для сравнения документов
    * Точность: 100%
    * Скорость обработки: 30.6 мс на документ
  * Особенности:
    * Высокая скорость обработки
    * Не требует OCR
    * Работает с изображениями документов напрямую
* OCR-решение (ветка ocr)
  * Подход: Распознавание текста с последующей классификацией
    * Точность: 100%
    * Скорость обработки: 1 с на документ
  * Особенности:
    * Полное распознавание текста
    * Возможность извлечения контента
    * Более универсальный подход
